# STM32 W5500 BMS Demo

A simple embedded web dashboard built with an **STM32F401 Black Pill** and **W5500 Ethernet controller**.

The current version is a demo: battery voltage telemetry is generated by a Python script on a PC, transmitted to the STM32 over UART, and displayed in real time in a web browser.

## Current data flow

```text
Python simulator
      |
      | UART 115200
      v
STM32F401 Black Pill
      |
      | SPI
      v
    W5500
      |
      | Ethernet
      v
 Web browser
```

## Features

- STM32F401 Black Pill
- W5500 Ethernet interface
- HTTP server running directly on the STM32
- UART telemetry input
- Live browser updates without page reload
- Battery voltage display
- Real-time voltage history graph
- Python telemetry simulator for testing

## Hardware

| Device | Interface |
|---|---|
| STM32F401 Black Pill | Main controller |
| W5500 | SPI3 |
| USB-UART adapter | USART1 |
| PC | Python simulator and web browser |

### W5500 connection

| Signal | STM32 |
|---|---|
| SCK | PB3 |
| MISO | PB4 |
| MOSI | PB5 |
| CS | PB6 |
| RESET | PB7 |

### UART connection

| USB-UART | STM32 |
|---|---|
| TXD | PA10 / USART1_RX |
| RXD | PA9 / USART1_TX |
| GND | GND |

UART configuration:

```text
115200 baud
8 data bits
No parity
1 stop bit
```

## Network configuration

The current firmware uses a static IP:

```text
STM32 / W5500: 192.168.1.177
Subnet mask:   255.255.255.0
Gateway:       192.168.1.1
```

For a direct Ethernet connection, the PC can be configured, for example, as:

```text
PC IP:       192.168.1.10
Subnet mask: 255.255.255.0
```

Open the dashboard at:

```text
http://192.168.1.177
```

Raw UART data is also available at:

```text
http://192.168.1.177/data
```

## Python telemetry simulator

Install pyserial:

```bash
pip install pyserial
```

Set the correct COM port in `voltage_test.py`:

```python
PORT = "COM22"
BAUD = 115200
```

Run:

```bash
python voltage_test.py
```

The simulator generates values such as:

```text
V:51.82
V:51.91
V:52.03
V:51.95
```

Each value is sent over UART in the following format:

```text
V:<voltage>\r\n
```

The STM32 receives the line, stores the latest value, and provides it through the `/data` HTTP endpoint.

The browser requests `/data` periodically and updates the voltage value and graph without reloading the whole page.
